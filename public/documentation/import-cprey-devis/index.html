Guide 3

Dessiner en important le résultat d'un CPREY-DEVIS

Utilisez les niveaux, pièces, appareils et pieuvres issus du configurateur comme base de dessin contrôlée.

Capture future : panneau Étude importée

Parcours d'import

  1. Importez le fichier JSON CPREY-DEVIS depuis le menu Projet.
  2. Vérifiez les niveaux et les pièces créés ou rapprochés avec les références existantes.
  3. Ouvrez le panneau Étude importée pour suivre les éléments à placer.
  4. Convertissez les demandes en appareillages physiques adaptés au symbole souhaité.
  5. Créez les regroupements lorsque plusieurs StudyDevice correspondent à un même appareillage placé.
  6. Placez les appareillages sur le plan en conservant leurs associations à l'étude.
  7. Renseignez les hauteurs et modes d'installation nécessaires.
  8. Placez les pieuvres prévues et indiquez leurs pièces desservies.
  9. Affectez les StudyDevice aux ports de pieuvres cohérents.
  10. Contrôlez les éléments restant à placer dans le panneau Étude importée.
  11. Contrôlez les longueurs de gaines et les raccordements.
  12. Travaillez niveau par niveau pour réduire les erreurs de localisation.
  13. Sauvegardez en local et sur SmartCPREY lorsque le projet est cohérent.

À vérifier

Un import ne remplace pas le contrôle terrain : relisez les pièces desservies, les ports affectés et les hauteurs techniques avant finalisation.
